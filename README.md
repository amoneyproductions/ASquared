# A² Website

A clean, minimal static website for A², a San Diego creative & marketing studio.

## Files
- `index.html` — the whole site (single page with anchor sections)
- `styles.css` — all styling

## Before going live
- Replace the placeholder tiles in the "Recent work" section with real photos/video
- Replace the "Photo of Ava & Amy" placeholder in the About section
- Update the contact email (currently `hello@yourdomain.com`) in `index.html` — search for `yourdomain.com`
- Update the Instagram link in the contact section

## Deploying
This is a static site — no build step needed. It's connected to Netlify for automatic deploys on every push to main.
